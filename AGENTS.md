# Project Guidelines: A Pet with Paws®

## Overview
This repository contains the official 4-page static website for **A Pet with Paws®** (Pet Travel Perfected).
The website is designed for trade shows and web presence to showcase products, brand ethos, and wholesale contact opportunities.

## Strict Coding Guidelines
1. **No Code Comments / Commit Notes in Source Code**: Do not write explanatory comments, commit notes, or temporary change comments inside HTML, CSS, or JS files. Keep the code clean, concise, and production-ready.
2. **Clean & Semantic HTML5**: Build clear, accessible, and semantic web pages.
3. **Responsive & Mobile-First**: Ensure 100% responsiveness and seamless display across mobile, tablet, and desktop viewports.
4. **Vanilla Technologies**: Use pure HTML, tailwind css, CSS, and modern JavaScript for maximum performance and fast loading without bloated dependencies.
5. **Brand Consistency**: Adhere strictly to the brand typography, color palette, product specifications, and imagery provided by the client.

## Page Structure
- **Page 1 (Home / Overview)**: Brand introduction, "The Ultimate Stylish Solution for Small Pets on the Go", Fashion • Function • Sustainability.
- **Page 2 (The Madison Carrier)**: Product details, dimensions (US & Metric), colors (Pecan, Cobalt Blue, Rose Pink), features, and high-resolution visuals.
- **Page 3 (Training Bags & Waste Bag Pouches)**: Meet Bentley, Meet Miles, Meet Oliver with dimensions, colorways, and features.
- **Page 4 (Why Carry / Wholesale & Contact)**: Brand mission ("People. Pooches. The Planet."), eco-friendly recycled textile details, wholesale/distribution info, WhatsApp, contact email, and QR code.
