# A Pet with Paws® — Pet Travel Perfected

A luxury, eco-conscious showcase website for **A Pet with Paws®**, challenging the boundaries of traditional pet travel by combining **Fashion, Function, and Sustainability**.

---

## 🌟 Brand Ethos & Mission

> **"People. Pooches. The Planet."**

A Pet with Paws® creates innovative, cruelty-free, and sustainable pet travel accessories using recycled PET textiles and high-grade vegan pebble leather.

---

## 📄 Website Pages & Structure

1. **[Home / Brand Overview](index.html)**
   - Hero presentation with brand vision and product highlights.
   - Interactive Trade Show Inquiry modal.
   - Core brand pillars: *Fashion • Function • Sustainability*.

2. **[The Madison Carrier](madison-carrier.html)**
   - Luxury airline-compliant pet carrier designed like a high-end designer tote.
   - Dual-unit specifications (US Imperial & Metric measurements).
   - Multi-angle studio showcases in 3 colorways: **Pecan Brown**, **Rose Pink**, and **Cobalt Blue** (Front, Mesh Airflow Window, Hardware & Clochette Detail, Open Top Interior).

3. **[Training Bags & Waste Pouches](training-pouches.html)**
   - **Meet Bentley**: Dual-compartment training bag with smartphone peek pocket, magnetic treat pouch, and belt attachment.
   - **Meet Miles**: Waste bag dispenser purse with circular rubber grommet aperture and keyring clip.
   - **Meet Oliver**: Denim Edition training bag with jeans-pocket styling.

4. **[Why Carry / Wholesale & Contact](wholesale.html)**
   - Sustainability impact and recycled bottle textile lifecycle.
   - Retailer and distributor partnership information.
   - Direct contact links, WhatsApp integration, and digital QR code.

## 🛠️ Technology Stack

- **HTML5**: Semantic, accessible markup.
- **Tailwind CSS**: Modern utility-first styling for responsive layouts.
- **Font Awesome**: Vector iconography.
- **AOS (Animate On Scroll)**: Smooth micro-interactions and scroll reveals.
- **Vanilla JavaScript**: Lightweight interactions, mobile drawer, and modal state management.

## 🚀 Getting Started

### Local Development
To preview the website locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx serve .
```

Open your browser and navigate to `http://localhost:8080`.
